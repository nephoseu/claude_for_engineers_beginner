# task-tracker

A small task management project used throughout today's Claude Code for Engineers course.

## Structure

```
task-tracker/
  backend/     Express API (Node.js)
  frontend/    React app (Vite)
```

## Getting Started

```
cd backend && npm install
npm run dev     # starts the API on :4000
npm test        # runs the test suite
```

```
cd frontend && npm install
npm run dev     # starts the frontend dev server
```

You'll build on this project throughout the day — your instructor will guide you through each step.
